# PHASE A–B–C SKILL MAP
## Addition

> Skill map adalah progression, bukan label kemampuan anak.

---

# FASE A
## Understand Addition

### A0 — Quantity Foundation
- mengenali jumlah;
- mencocokkan simbol dan kuantitas;
- membandingkan jumlah;
- subitizing sederhana.

### A1 — Joining
- dua kelompok digabung;
- memahami total;
- menggunakan benda nyata.

### A2 — Counting All
- menghitung seluruh objek setelah digabung.

### A3 — Counting On
- mulai dari bilangan tertentu;
- tidak selalu kembali menghitung dari satu.

### A4 — Part–Part–Whole
- memahami bagian dan keseluruhan;
- melihat berbagai decomposition.

### A5 — Number Bonds
- pasangan pembentuk bilangan;
- fleksibilitas komposisi/dekomposisi.

### A6 — Make 5 / Make 10
- menggunakan struktur lima dan sepuluh.

### A7 — Doubles
- 2+2;
- 3+3;
- dst secara konseptual.

### A8 — Near Doubles
Setelah doubles dipahami.

### A9 — Number Line
- bergerak maju;
- melihat jarak penambahan.

### A10 — Symbolic Addition
- menghubungkan model dengan `a + b = c`.

### A11 — Story Problem
- joining/add-to sederhana.

### A12 — Explain Strategy
- counting-all;
- counting-on;
- make-ten;
- cara lain.

### A13 — Transfer
- menemukan penjumlahan di lingkungan nyata.

---

# FASE B
## Understand Structure & Place Value

### B1 — Place Value Addition
- satuan;
- puluhan;
- ratusan;
- ribuan.

### B2 — Expanded Form
Contoh:

```text
48 + 25
= 40 + 8 + 20 + 5
```

### B3 — Regrouping
Memahami bahwa:

```text
10 ones = 1 ten
10 tens = 1 hundred
```

Bukan “simpan satu” tanpa makna.

### B4 — Base Ten Representation
- blocks;
- place-value chart.

### B5 — Mental Addition
- puluhan penuh;
- ratusan penuh;
- decomposition.

### B6 — Friendly Number
Contoh:

```text
48 + 7
→ 50 + 5
```

### B7 — Compensation
Contoh:

```text
39 + 24
→ 40 + 23
```

### B8 — Standard Algorithm
Diperkenalkan setelah konsep place-value/regrouping kuat.

### B9 — Estimation
- memperkirakan besar hasil;
- memeriksa kewajaran.

### B10 — Contextual Problem
- uang;
- ukuran;
- data;
- kegiatan harian.

### B11 — Compare Strategies
Memilih strategi paling masuk akal untuk bilangan tertentu.

---

# FASE C
## Strategic & Flexible Addition

### C1 — Large Number Structure
Place-value pada bilangan lebih besar.

### C2 — Efficient Strategy Selection
Anak memilih:
- mental;
- compensation;
- decomposition;
- standard algorithm;
- estimation.

### C3 — Multi-step Problem
Menentukan informasi relevan dan urutan operasi.

### C4 — Measurement Context
Penjumlahan dalam pengukuran.

### C5 — Time Context
Durasi dan waktu sesuai ruang lingkup pembelajaran.

### C6 — Money & Data
Total, tabel, dan situasi nyata.

### C7 — Decimal/Fraction Context
Digunakan hanya sesuai progression kurikulum yang diterapkan.

### C8 — Estimation & Reasonableness
Sebelum dan sesudah menghitung.

### C9 — Error Analysis
Menjelaskan mengapa solusi tertentu keliru.

### C10 — Multiple Solutions
Membuat beberapa solusi/ekspresi yang memenuhi kondisi.

### C11 — Mathematical Argument
Memberikan alasan dan bukti sederhana.

### C12 — Transfer
Menggunakan strategi pada situasi baru.

---

# Cross-Phase Competencies

Semua fase mengembangkan:

1. represent;
2. reason;
3. choose strategy;
4. explain;
5. check;
6. apply.

---

# Advancement Rule

Jangan membuka level hanya karena jumlah soal selesai.

Gunakan kombinasi evidence:

- akurasi;
- bantuan;
- consistency;
- strategy;
- representation;
- explanation;
- transfer.

Contoh:

```text
3 aktivitas Independent
+
1 reasoning task berhasil
+
1 transfer task berhasil
→ candidate for next scaffold level
```

Aturan final perlu diuji secara empiris, bukan dianggap benar hanya karena masuk akal secara teknis.
